# Omarchy Orb 模拟器 v3 · 相对 v2 的变更说明

致：Joi（审阅）　日期：2026-10-21
文件：`/workspace/work/orb/v3/index.html`（单文件，内联 CSS/JS，无外部依赖、无网络请求）
规格：`/workspace/projects/dd86e712-f01c-48ac-b8c5-7b89eb3821db/spec/omarchy-orb-v3-spec.md`（v0.2 定稿草案）

## 1. 方向变化
| | v2 | v3 |
|---|---|---|
| 主形态 | ESP32 466×466 圆屏为唯一设备 | **手机 PWA 为主**（小米 17 Pro / iPhone 竖屏单手），圆屏为后续配件 |
| 外壳 | 只有圆屏 | 顶部切换「手机」（默认 390×844）/「圆屏 ESP32」，两者渲染**同一个 modules 注册表** |
| 通道 | BLE HID 为主，Bridge 为辅 | X1 remote-daemon HTTP/WS 为唯一通道；BLE HID 只留给未来 ESP32 做底盘 |

## 2. 页面：15 → 4
**保留并重做**：正在播放（并入原「音量」页）、工作区、快捷、PTT。
**删除**：启动器、音量（独立页）、播客节目/剧集、音乐选歌（字母环）、多主机/配对、电视、设置、模块排序、宠物待机、手势仲裁表页。
新增：正在播放的**空状态**（音乐/播客/视频三个打开键）；正在播放**自动跟随**当前 MPRIS 播放器（原 v2 需手动选播放源）。

## 3. 手势：重定规则
| 项 | v2 | v3 |
|---|---|---|
| 播放/暂停 | 双击（单击延迟 300ms 等待） | **轻点立即执行**，取消双击 |
| 音量 | 边缘旋钮 ±2%/格 | 手势板**上下拖**，实时显示数值 |
| 切歌 / ±15s | 按钮 | **左右快滑**（≤280ms、≥0.45px/ms、≥36px） |
| 拖进度 | 边缘旋钮 5s/格 | **左右慢拖**，显示目标时间，松手 seek |
| 静音 | 音量页中心按钮 | **长按 600ms** |
| 方向判定 | 按起点分区（外圈=旋钮、底边=上滑） | **只看方向**：首个 12px 位移锁定主轴，不分区 |
| 翻页 | 左右滑 = 核心页循环 | **左右滑不翻页**；手机底部标签栏、圆屏实体键「上一/下一模块」 |
| 全局手势 | 底边上滑 / 长按中心 → 启动器 | 删除（无启动器） |
| 圆屏边缘旋钮 | 有 | **暂删**（列入待确认） |

## 4. 软件结构（新）
- JS 分区注释：`CORE`（util、gesture engine、command log、transport mock、state store、feedback、registry+nav、shells、boot）与 `MODULES`。
- 手势引擎为**纯函数**，包在 `/*<GESTURE>*/ … /*</GESTURE>*/` 标记内，测试脚本直接提取运行。
- **模块合同**：`{id, name, icon, layout, gestures, commands, reads, voice, render(shell, view)}` + 补充字段 `handle(evt, ctx)`（事件入口；任务说明中的合同未列，实际需要，请审阅是否纳入正式合同）。注册时校验必填字段。
- 传输层 mock：`GET /state`、`WS /ws`（JSON Merge Patch 增量；1s 推进度、约 14s 切一次窗口标题）、`POST /cmd {module,action,args}`、`POST /ptt`（multipart）。页内 `MockDaemon` 代表 X1 真相，客户端只经 Transport 访问。
- **命令日志**面板：显示真实将发送的 JSON 与响应；`[本地]` 标注乐观更新、模块切换、换肤等不出网行为；`_exec` 字段只是示意 daemon 将执行的命令（mock 专用，正式协议不含）。
- 皮肤：内容只引用 CSS 变量；Tokyo Night（深）/ 浅色两套，只换变量。
- 指针委托在屏幕根节点，模块每次重绘不打断进行中的手势；只对 `[data-pad]/[data-act]/[data-hold]` 捕获指针。
- URL 参数便于截图/审阅：`?shell=orb&theme=light&player=podcast|video|none&mod=workspaces`。

## 5. 模拟器控制台（外壳外）
外壳切换、主题切换、模拟播放器类型（音乐/播客/视频/无播放器）、「下次 PTT 说」示例句选择（默认轮换 7 句，含 1 句第3层）、命令日志（可选显示每秒进度推送、清空）。

## 6. 规格层面的新增/待你拍板
- `player.kind`、`player.art` 两个**建议新增**字段（v2 无）。
- WS 增量格式定为 `{"type":"patch","data":{…}}` + RFC 7386 合并语义。
- 连接安全用共享令牌（Bearer），首次扫码写入——新提议，原草稿未写。
- 快滑方向取「右=下一首/+15s」，与慢拖的时间轴方向一致。
- PTT <300ms 丢弃。

## 8. 已知问题
- 封面为占位色块；真实封面取色留到「皮肤动效」单。
- 录音为模拟：未调用 `getUserMedia`（离线、无权限弹窗），波形为时间驱动的假电平。
- 播放/暂停发 `toggle`，若客户端状态陈旧可能与用户预期相反；可改为按当前显示状态发 `play`/`pause`，待 daemon 接口核对后定。
- 「打开播放器」「点歌」的 daemon 实际命令未定（mock 中为示意）。
- 手机外壳在矮窗口会整体等比缩小；拖动距离已按缩放折算，但手感阈值以真机为准。
- 快捷「关闭窗口」无二次确认。
