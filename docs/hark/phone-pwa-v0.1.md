# Omarchy Orb 手机版规格 v0.1（草稿，2026-10-21，待用户圈改）
方向：手机 PWA 为主，由 X1 remote-daemon(:8767) 提供页面+WebSocket；ESP32 为后续实体配件，共用协议/模块合同。
① v1 模块：正在播放(含音量；空状态 音乐/播客/视频 打开键)、工作区1–9+窗口名、快捷(截图/锁屏/关窗/启动器)、PTT(固定命令+点歌)。推后：媒体库、电视、多主机、宠物、PTT Agent 层、ESP32。不做：红外(用小米遥控)、蓝牙。
② 交互：竖屏单手；上 3/5 手势板：点=播放暂停(立即)、上下拖=音量、左右快滑=切歌(播客/视频±15s)、左右拖=进度、长按=静音；只看方向；模块切换走底部标签；按钮≥56px，每屏主按钮≤4；震动反馈(安卓)。
③ 内核冻结(手势引擎/导航/WS连接/皮肤)；模块=文件夹，申报 图标/版式/手势/命令状态/语音句式；daemon 侧模块=插件+cards.json。
④ 协议：GET / ；GET /state(扩展)；WS /ws 增量(MPRIS、socket2、音量)；POST /cmd {module,action,args}；POST /ptt。录音需 HTTPS(内网域名+自签)。
⑤ 分单：骨架(页面+WS+播放暂停端到端)→正在播放→工作区+快捷→PTT→皮肤动效。每单只改自己模块目录、git、验收清单；改内核单独审批。
待定：主力手机(小米/iPhone)；v1 是否就这 4 个模块。
